Pain Points

확신이 없어서
구매를 못 한다

65명 설문 + 성수 핑크오피스 현장 방문(IDI)을 통해 도출한 4가지 핵심 문제입니다.

01
글로벌 진입 구조가 너무 헷갈려요

한국/글로벌/US로 분리 운영되며 각 사이트의 구조가 달라 일관된 경험이 없습니다. 사용자가 어디서 구매해야 하는지 인지하지 못합니다.

02
색조 브랜드인데 어떤 컬러를 선택해야 할지 모르겠어요

60.3%가 제품 설명을 이해하기 어렵다고 응답. 다양한 피부톤에서의 발색 확인이 불가능하고, 컬러 비교 UI가 전무합니다.

03
나한테 맞는 제품이 어떤건지 모르겠어요

55%가 디자인·가독성 불편을 꼽았습니다. 퍼스널 컬러 기반 탐색 구조가 없어 '검색형 쇼핑'으로 전락, 탐색 이탈이 발생합니다.

04
그래서... 롬앤은 어떤 브랜드인 거죠?

브랜드 소개 페이지가 일부 사이트에만 존재합니다. 글로벌 사용자가 브랜드 철학을 이해하지 못한 채 쇼핑하게 됩니다.

핵심 인사이트

사용자는 정보가 부족해서가 아니라,
'확신이 없어서' 구매를 못 한다.

Solution

색 선택 경험을
판매하는 웹사이트

4가지 핵심 문제를 해결하기 위해 설계한 솔루션입니다.

🎨

퍼스널컬러 진단 페이지

피부톤 기반 진단 테스트로 맞춤 제품을 추천. 자사 앱 아이컬러 연동. 웹사이트 체류 시간과 전환율을 동시에 높입니다.

신규 페이지
🏬

핑크오피스 페이지 신설

오프라인 체험 공간을 웹에서 경험. QR 결제, 레일 배송 등 핑크오피스만의 경험을 페이지로 구현해 브랜드 정체성을 전달합니다.

신규 페이지
📖

브랜드 소개 페이지 통합

COHA 커뮤니티, 그린케미 프로젝트, 개발일지 등 브랜드 스토리를 글로벌 사이트에 통합. 신뢰 기반 구매 결정을 유도합니다.

UX 통합
🛒

퀵샵 (구매 경로 단축)

메인 화면에서 바로 장바구니 담기. 상품 라인별 색상 스와치 제공으로 탐색과 구매가 끊기지 않는 흐름을 설계했습니다.

전환율 개선
💄

색상 비교 UI + 다양성 반영

전 색상 발색 사진, 피부톤별 필터, 다인종 모델 콘텐츠 제공. 60.3%가 불편하다고 한 제품 정보를 직관적으로 재설계했습니다.

콘텐츠 강화
Design Process

더블 다이아몬드,
5주간의 여정

Discover → Define → Develop → Deliver, Double Diamond 프레임워크 기반으로 진행했습니다.

01
02.25 — 03.05 · Discover

Research & Insight

K브랜드 선정 → STEEP 분석, 경쟁사 포지셔닝 → 65명 설문 + 성수 핑크오피스 현장 방문(IDI) → 어피니티 다이어그램으로 페인포인트 도출.

#DeskResearch#STEEP#IDI#Survey
02
03.05 — 03.07 · Define

문제 정의 & 전략 수립

Lean Canvas 작성, 페르소나 2개(틱톡 인플루언서, 드럭스토어 직원) 설정, 개선 User Flow 설계. 핵심 문제: "확신이 없어서 구매를 못 한다."

#LeanCanvas#Persona#UserFlow
03
03.09 — 03.24 · Develop

IA / 와이어프레임 / UI 디자인

IA 재설계 (브랜드 이해→탐색→개인화→관계 형성 플로우), Figma 컴포넌트 시스템 구축, 퍼스널컬러·핑크오피스·브랜드 페이지 디자인 완성.

#IA#Wireframe#Figma#DesignSystem
04
03.24 — 03.31 · Deliver

개발 & 최종 발표

HTML/CSS/JS 기반 개발. Claude Code + OpenAI Codex 활용으로 기능 구현 가속. GitHub Pages 배포 후 최종 발표 완료.

#HTML/CSS/JS#GitHub Pages#Claude Code
